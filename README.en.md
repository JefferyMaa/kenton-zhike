# Zhike (知客)

[English](README.en.md) | [简体中文](README.md)

Zhike is a local comment-assistant tool for Chinese Douyin creators, running on macOS / Windows. It reads unreplied public comments and drafts replies only from the business Q&A you configure; nothing is sent until you preview each item and confirm a review batch.

![Zhike v2.1.0 activation page — core business steps stay locked until activated](docs/assets/zhike-v2.1.0-activation.jpg)

## Is Zhike right for you?

Zhike fits creators or small teams who answer public comments with fixed business scripts and are willing to review every reply before it is sent.

The current version requires:

- Mac Apple Silicon or Windows x64;
- network access to the software download sources, the Zhike license service, and Douyin;
- your own Douyin account;
- a valid Zhike online license key (卡密).

If you need fully automatic sending without human review, direct-message access, free-form replies generated by cloud LLMs, or a guarantee of zero platform risk, this version is not for you.

> Zhike is an independent third-party tool. It is not affiliated with, authorized, or endorsed by Douyin (ByteDance). Any automation may trigger platform rules or account risk.

## First run in 5 minutes

1. Download the ZIP and verify its SHA-256.
2. Unzip and run the launcher: on macOS double-click `启动.command` (if blocked on first open, right-click the file in Finder and choose "Open"); on Windows double-click `启动.bat`.
3. Wait for the first-time environment setup. The launcher installs hash-locked Python dependencies and downloads Chromium; later launches reuse the local environment.
4. On the local page, enter the license key you received at purchase to activate.
5. Scan the QR code with your own Douyin account, fill in your business Q&A, and generate a per-item preview first.
6. Check the video, user, original comment, and drafted reply for each item, then confirm the review batch to send.

Full steps: [Quickstart guide](docs/quickstart.md) (Chinese).

## Key features

- Reads unreplied public comments under your own account;
- Drafts replies only from your local business Q&A library; skips when nothing matches;
- Price questions get a draft reply only when they hit a configured FAQ;
- Shows a per-item preview and freezes a one-time review batch before sending;
- Isolates login state, settings, quotas, and the send ledger per account;
- Supports custom random intervals, daily caps, and Beijing-time active hours;
- Distinguishes confirmed, unknown, and failed send results; unknown results are never blindly retried;
- Supports exporting and wiping local business data.

## License key and network boundary

Downloading the software does not grant a usage license. Before activation, only startup diagnostics, license activation/status, and local data export/wipe are available; all other business APIs are rejected by default.

The license key, product identifier, and device identifier are sent to the Zhike license server during activation, at startup, and periodically at runtime, for device binding, expiry, and revocation checks. At runtime the status refresh window is at most about 1 hour.

## Data and privacy

Platform login state, business Q&A, comment processing records, and the send ledger stay on your own computer by default; they are not sent to the Zhike license server or to external LLMs. The software accesses:

- Douyin, for the login and comment operations you initiate;
- Python package and Chromium download sources, for first-time setup;
- the Zhike license service, for license verification.

The current product does not read or store direct messages. Public comments may contain third-party personal information; users are responsible for handling them in compliance with applicable laws and regulations.

## Known limitations

- Current builds target Mac Apple Silicon and Windows x64.
- The ZIP runs via `启动.command` / `启动.bat`: the macOS build is not an Apple-notarized `.app` bundle; the Windows build is not code-signed, so SmartScreen may warn.
- Keyword matching can still produce false hits; always review before sending.
- Changes to Douyin pages, APIs, or platform rules may break functionality.
- The online license key is a soft license. Both the macOS and Windows builds ship as plaintext Python and cannot stop someone with local admin rights and reverse-engineering skills from analyzing or modifying the code, so we make no "uncrackable" claims.
- Using the software does not mean the platform permits automation, nor that your account will not be restricted.
