# 知客 v2.1.7 发布说明

发布日期：2026-08-09

## 本次更新

- macOS Apple Silicon 与 Windows x64 的核心 Python 模块改为使用 PyArmor Basic 混淆，提高直接复制和逆向分析成本；混淆不等于加密，也不代表无法破解。
- 两端制品都绑定同一源码提交与受控构建证明；包内版本为 2.1.7，`source_dirty=false`，并继续使用在线卡密门。
- Windows 候选在生成 SHA 校验文件前先核对注册构建设备生成的最终 ZIP；错误 SHA 不会产生新的 sidecar 或发行证据。
- Windows 真实买家烟测覆盖托管 Python 3.12.11、Chromium、`/healthz`、错误卡、过期卡、无卡业务接口和一次性会话重放拦截。
- 每次真实发送点击前仍会立即在线复核授权；到期、断网、服务异常或授权状态未知后不再发起新点击。平台已经受理的点击无法撤回。

## 首次打开边界

当前发行包未使用商业代码签名，macOS 也未做 Apple 公证。

- macOS：首次右键 `启动.command` 选择「打开」；若仍被阻止，到「系统设置 → 隐私与安全性」点「仍要打开」。
- Windows：普通 SmartScreen 提示可在核对来源和 SHA-256 后选择「更多信息 → 仍要运行」。若 Smart App Control 直接阻止，当前未签名版不兼容；不要为了知客关闭系统安全功能。

下载软件不等于获得授权。核心业务功能仍必须使用有效卡密激活，并在启动和运行中联网复核。
