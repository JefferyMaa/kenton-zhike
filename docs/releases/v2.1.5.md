# 知客 v2.1.5 发布说明

发布日期：2026-08-09

## 本次更新

- 第四步界面重组为运行控制、本次运行、系统状态与发送账本，关键状态更集中。
- 待人工确认记录不会因为账本只显示最新 30 条而被隐藏；读取失败会明确提示，不再显示成空账本。
- 图标全部随软件内置，不访问外部图标 CDN；补齐键盘方向键切换和手机端布局。
- macOS Apple Silicon 与 Windows x64 使用同一版 2.1.5、同一套在线卡密门和评论发送安全规则。
- Windows SHA-256 校验文件固定使用 LF 行尾，官网包与 GitHub ASCII 包按原始字节复核一致。
- 每次真实点击前立即复核授权；授权失败、断网、状态未知或到期后不再发起新点击。平台已经受理的点击无法撤回。

## 首次打开边界

当前发行包未使用商业代码签名，macOS 也未做 Apple 公证。

- macOS：首次右键 `启动.command` 选择「打开」；若仍被阻止，到「系统设置 → 隐私与安全性」点「仍要打开」。
- Windows：普通 SmartScreen 提示可在核对来源和 SHA-256 后选择「更多信息 → 仍要运行」。若 Smart App Control 直接阻止，当前未签名版不兼容；不要为了知客关闭系统安全功能。

下载软件不等于获得授权。核心业务功能仍必须使用有效卡密激活，并在启动和运行中联网复核。
