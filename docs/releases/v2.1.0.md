## 本版重点

- 在线卡密成为所有业务入口的默认门禁；
- 运行中持续复核到期、设备和吊销状态；
- 预览、一次性审核批次、发送状态和配额形成完整闭环；
- 中国用户的调度与统计统一按北京时间；
- 增加数据导出、恢复、清除和保留期合同；
- 发行包使用固定依赖、文件哈希清单和干净源码 revision。

## 安装提示

当前通过 ZIP 和 `启动.command` 交付，不是 Apple 公证的 `.app`。macOS 首次阻止打开时，请在 Finder 中右键 `启动.command` 并选择“打开”。首次启动需要联网下载固定版本依赖和 Chromium。
